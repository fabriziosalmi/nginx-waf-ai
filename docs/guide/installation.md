# Installation

Learn how to install, set up, and configure **Nginx WAF AI**.

## Prerequisites

Ensure you have the required runtime environment and dependencies installed on your system.

## Setup

Refer to the official repository README and release notes:

```bash
# Clone the repository
git clone https://github.com/fabriziosalmi/nginx-waf-ai.git
cd nginx-waf-ai
```

For advanced configuration and API usage, refer to the source code on [GitHub](https://github.com/fabriziosalmi/nginx-waf-ai).
